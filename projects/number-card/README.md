# 숫자 카드 게임

카드·덱·플레이어·AI 진행·저장 기능을 분리한 Pygame 게임입니다. 메뉴에서 수업 모드를 전환할 수 있습니다.

## 실행
```bash
python -m pip install -r requirements.txt
python main.py
```
한글 표시에는 맑은 고딕 또는 Noto Sans CJK 등의 한글 글꼴이 필요합니다. 저장 파일은 실행 중 생성되는 로컬 상태입니다.

## 확인 범위
소스 문법을 검사했습니다. 이번 정리 과정에서 GUI 전체 플레이와 AI 난이도 균형은 다시 검증하지 않았습니다.
