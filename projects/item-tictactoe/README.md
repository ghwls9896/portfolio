# 틱택톡: 아이템 에디션

틱택토에 아이템과 AI/PvP 옵션을 결합한 Pygame 게임입니다. 규칙, 보드 모델, AI, 화면을 모듈로 분리했습니다.

## 실행
```bash
python -m pip install -r requirements.txt
python game.py
```
한글 표시에는 맑은 고딕 또는 Noto Sans CJK 등의 한글 글꼴이 필요합니다. 저장 파일은 실행 중 생성되는 로컬 상태입니다.

## 확인 범위
소스 문법을 검사했습니다. 이번 정리 과정에서 GUI 전체 플레이와 AI 난이도 균형은 다시 검증하지 않았습니다.
