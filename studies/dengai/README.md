# DengAI · 주간 환자 수 예측

도시별 환경·시계열 특성을 탐색하고 모델 예측과 도시·주차 계절 평균을 혼합한 팀 과제입니다. 노션 EDA 이후 작성된 최종 제출 노트북을 포함했습니다.

로컬 최종 보고서에는 Public MAE **15.6563**, 94위가 기록되어 있습니다. 이는 **저장된 보고서의 기록**이며 현재 리더보드를 재조회한 수치가 아닙니다. 최종 제출에는 수동 후처리가 포함되므로 순수 모델의 독립 검증 성능과 구분해야 합니다.

`analysis.ipynb`는 출력과 개인 학번을 제거한 소스 스냅샷입니다. 노트북이 참조하는 DengAI 학습/시험 CSV는 대회 제공처에서 별도로 준비합니다. 팀 작업이며 개인별 기여 비율은 자료에서 확인되지 않아 기재하지 않았습니다.
