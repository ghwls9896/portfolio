## 읽는 순서
분포와 정보량을 먼저 이해하고, 시간에 따라 상태를 갱신하는 RNN으로 넘어갑니다. 마지막에는 한글 수사를 다음 문자 예측 문제로 만들고, LSTM이 무엇을 기억하는지 시각화로 해석합니다.

강의 원본/정답 전체는 포함하지 않습니다. Attention·Transformer·VAE·GAN·Diffusion의 전체 구현을 완료했다는 뜻은 아닙니다.
